#### 🛠️ Internal systems I've built and run

Real tools, running in production, mostly private because they touch client and business data — named here because they're the evidence this is a genuine, working system, not a portfolio piece:

- **Project Hub** — a local dashboard giving one view of every project on the drive, with an on-demand AI pass connecting work across them.
- **Site Studio** — the workbench where all six sites are built, edited and released: a shared theme and block layer, a page editor, and gated releases that check every build first and roll a bad one back. Its public edition, **[Postwright](https://tools.belchamber.us/postwright/)**, is on the way ([case study](https://belchamber.us/work/postwright/)).
- **Site Ops** — site health monitoring and infrastructure automation (SSH orchestration, encrypted credentials, rollback-safe updates) behind all six live sites.
- **CS Powerhouse** — content and marketing operations: from idea to published article across every site.
- **Media Hub** — the one media service: every image and video the sites publish, plus analysis of the video archive.
- **Crash Labs** — stands up local copies of any of these systems from any branch, close enough to production to test end to end.
- **auth-service-v1** — the JWT authentication backend behind my apps (successor to the WordPress-based bridge below).
- **claude-skills** — a versioned library of custom AI agent skills I use to run this whole estate.
- **e2e-kit** — a shared browser/E2E testing framework used across every project.
